## 📁 Project 1: Data Classification Using AI (Iris Dataset)
**Folder:** `Decode-P1`

**Goal:** Build a basic classification model using a small dataset to predict flower species.

**Pipeline:**
- Loaded and explored the Iris dataset (150 samples, 4 features, 3 classes)
- Applied feature scaling using `StandardScaler`
- Split data into training (80%) and testing (20%) sets
- Trained a **K-Nearest Neighbors (KNN)** classifier
- Evaluated performance using a **Confusion Matrix**, **Classification Report**, and **F1 Score**

**Result:** 93% accuracy | F1 Score: 0.93

**Tech Stack:** Python, scikit-learn, pandas, NumPy
